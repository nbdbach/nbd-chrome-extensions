NBD Auto Refresh

Privacy Policy

Last updated 31 August 2026

NBD Auto Refresh collects nothing.

What is not collected

  • No personal or identifying information.
  • No browsing history, page content, page titles, or URLs.
  • No analytics, telemetry, crash reporting, or usage statistics.
  • No advertising or tracking identifiers.

What is stored, and where

The extension keeps two things in your own browser, using Chrome's storage API:

  • The refresh interval and options you last chose.
  • Which tabs are currently set to refresh, for the current browser session.

Both stay on your device. Neither is transmitted anywhere, and both are removed when you uninstall the extension.

Network access

The extension makes no network requests of any kind. It loads no remote scripts, no external fonts, and no remote configuration. It reloads the tab you point it at, and that request goes from your browser to that site exactly as it would if you pressed the reload button yourself.

Permissions

alarms
Schedules the periodic reload you configure.
storage
Remembers the settings described above.

That is the entire list. The extension requests no host permissions, injects no content scripts into pages, and cannot read the content of any page you visit. It does not request the tabs permission, which is what would let it read your browsing history.

Third parties

There are none. No data is shared, sold, or transferred, because none is collected. The extension has no server component.

Verifying this

The extension is open source under the MIT licence. Every release is built from a public tag, and the exact package submitted to the Chrome Web Store is attached to that release, so you can rebuild it yourself and compare.
